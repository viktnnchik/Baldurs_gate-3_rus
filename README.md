# Русский язык и озвучка для Baldur's Gate 3

Программа `BG3_Russian_Installer.exe` сама делает всё, что описано в ручной инструкции по смене языка.

## Меню программы

1. Русификатор + русская озвучка
2. Только русификатор (текст)
3. Только русская озвучка
4. Вернуть английский язык
5. Удалить русскую озвучку

## Озвучка

Русификатор вшит в exe. Озвучка (нейросетевая, например проект SynthVoiceRu) в exe **не вшита**: её автор распространяет сам, а лицензия на перепаковку неизвестна. Скачайте её сами и:

- положите `.zip`/`.pak` с «voice», «озвуч» или «synth» в имени рядом с exe, либо
- укажите путь или ссылку в меню, либо
- `BG3_Russian_Installer.exe --voice-src=<путь или ссылка>`.

`.pak` копируется в `%LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\Mods`, а мод прописывается в `modsettings.lsx` (если в архиве есть `info.json`; иначе включите его в BG3 Mod Manager). Список установленного хранится в `Data\bg3_rus_voice_manifest.json`, по нему пункт 5 всё убирает. Озвучка не проверялась на реальной игре.

## Как пользоваться

1. Скачайте [`dist/BG3_Russian_Installer.exe`](dist/BG3_Russian_Installer.exe). Внутри уже есть `Russian.pak`, больше ничего качать не нужно.
2. Запустите его и выберите нужный пункт меню.
3. Если игра стоит в `Program Files`, Windows попросит права администратора. Согласитесь.
4. Запустите игру.

Чтобы вернуть английский, запустите программу и выберите `4`.

## Что делает программа

1. Ищет игру: в библиотеках Steam (через реестр и `libraryfolders.vdf`), в обычных папках Steam и GOG на всех дисках и в папке, где лежит сам exe. Если ничего не нашлось, попросит вставить путь вручную. Путь можно передать и первым аргументом.
2. Переносит в `Data\Localization\_backup_bg3_rus\<дата>` все файлы, кроме
   `English_Animations.pak`, `Language.lsx`, `Voice.pak` и `VoiceMeta.pak`.
   Файлы **не удаляются**, их можно вернуть.
3. Создаёт `Data\Localization\Russian\Russian.pak`.
4. Меняет в `Language.lsx` значение `value="English"` на `value="Russian"`. Исходный файл сохраняется как `Language.lsx.bak`.

При возврате английского (`4` или `--restore`) файлы из резервной копии возвращаются на место, а в `Language.lsx` снова прописывается `English`.

## Параметры командной строки

```
BG3_Russian_Installer.exe [путь к игре] [--text] [--voice] [--all] [--voice-src=...] [--restore] [--remove-voice]
```

## Сборка

Нужен Go 1.21 или новее:

```
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-s -w" -o dist/BG3_Russian_Installer.exe .
```
