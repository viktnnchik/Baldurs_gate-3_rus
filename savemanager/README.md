# Менеджер сохранений Baldur's Gate 3

`dist/BG3_SaveManager.exe` — окно с кнопками, без установки.

- **Копировать все / выбранные** — упаковывает сохранения в zip в `Documents\BG3_SaveBackups`.
- **Восстановить** — возвращает сохранения из копии. Перед этим делается страховочная копия того, что будет перезаписано.
- **Автокопия** — раз в N минут, только если сохранения изменились. Хранится заданное число автокопий.
- Папку сохранений можно поменять в настройках (по умолчанию `%LOCALAPPDATA%\Larian Studios\Baldur's Gate 3\PlayerProfiles\Public\Savegames\Story`).

Окно открывается в Edge/Chrome (режим приложения), сервер слушает только `127.0.0.1` и закрывается вместе с окном. Автокопии работают, пока окно открыто.

Сборка: `GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-s -w -H windowsgui" -o ../dist/BG3_SaveManager.exe .`
